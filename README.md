# Личная CRM

Приложение для ведения личных контактов. Идея и ограничения — `specs/01-продуктовая-идея.md`.

## База данных

PostgreSQL работает в Docker. Нужен установленный и запущенный Docker Desktop.

1. Создать файл настроек: скопировать `.env.example` в `.env` и заполнить значения
   (пароль — любая длинная случайная строка; порт — свободный порт на компьютере, например `5435`).
2. Запустить базу:

   ```
   docker compose up -d
   ```

3. Проверить, что база работает:

   ```
   docker compose ps
   ```

   В колонке `STATUS` должно быть `healthy`.

Остановить базу: `docker compose stop`. Данные при этом сохраняются.

База доступна только с этого компьютера, по адресу из `DATABASE_URL` в `.env`.

## Приложение

Нужны Node.js и pnpm. База должна быть запущена (см. выше).

1. Установить зависимости:

   ```
   pnpm install
   ```

2. Создать таблицы в базе (безопасно запускать повторно — применяет только новые изменения):

   ```
   pnpm db:migrate
   ```

3. По желанию — заполнить базу тестовыми данными (1000 контактов с заметками).
   Срабатывает, только если в базе ещё нет ни одного контакта, поэтому настоящие данные не тронет:

   ```
   pnpm db:seed
   ```

4. Запустить приложение:

   ```
   pnpm dev
   ```

   и открыть http://localhost:3000

Для быстрой работы без режима разработки: `pnpm build`, затем `pnpm start` (тот же адрес).

С телефона или другого компьютера в той же сети приложение открывается по адресу из строки `Network` при запуске
(например, `http://172.16.3.36:3000`). Входа в приложении нет, поэтому контакты видны всем в этой сети.

## Что умеет

- Главная — список всех контактов по алфавиту, поиск по имени (можно по части имени, в любом порядке слов, «е» и «ё» не различаются)
- «Добавить контакт» — имя, кто это, откуда знакомы, телефон, почта. После сохранения новый контакт подсвечен в списке
- Карточка контакта — все данные, кнопка «Изменить» и заметки: что обсудили, о чём договорились. Новые заметки сверху, с датой
- Данные хранятся в базе на сервере, поэтому в любом браузере видны одни и те же контакты
